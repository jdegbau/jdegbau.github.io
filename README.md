# jdegbau.github.io

This repository is now migrated to Astro.

## Local development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the site:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Notes

- Static assets are served from `public/assets/`.
- Blog content lives in `src/content/blog/`.
- The site uses Astro page routes in `src/pages/`.
- Legacy Jekyll files have been removed from the working tree.
